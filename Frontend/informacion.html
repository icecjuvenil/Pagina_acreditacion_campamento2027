¿Qué debes llevar?

Prepara con anticipación los elementos necesarios para los tres días.

  • 📖 Biblia y cuaderno de apuntes.
  • 👕 Ropa cómoda y decorosa.
  • ☀️ Protector solar.
  • 👟 Zapatillas.
  • 🩴 Chalas de agua para la piscina y la ducha.
  • 🩱 Traje de baño o ropa para mojar.
  • 🧴 Útiles de aseo personal: shampoo, pasta dental y otros elementos necesarios.
  • 🛁 Toalla de baño y otra toalla para la piscina.
  • 🛏️ Sábanas de una plaza y media y almohada.
  • 🛍️ Bolsa para ropa sucia.
  • 🍪 Snack personal, si lo deseas.
  • 👔 Ropa formal para el regreso a la iglesia.
